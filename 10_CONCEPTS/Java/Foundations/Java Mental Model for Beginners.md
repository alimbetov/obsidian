# Java Mental Model for Beginners

> [!summary]
> Программа Java — это последовательность команд, которые работают со значениями. Переменные дают значениям имена, объекты объединяют связанные данные и действия, а поток выполнения показывает, какая команда выполняется сейчас.

## 1. Значение

Значение — конкретная информация:

```text
5
true
"Almaty"
```

Число `5` — значение. Текст `"Almaty"` — значение. Значение не обязано иметь имя.

## 2. Переменная

Переменная — именованное место, через которое программа получает значение.

```java
int age = 14;
```

Разберём строку:

| Часть | Смысл |
|---|---|
| `int` | разрешённый вид значения |
| `age` | имя переменной |
| `14` | значение |
| `=` | присваивание |

> [!warning]
> Переменная не является коробкой в буквальном смысле. Это учебный образ. Точное поведение зависит от типа значения и места хранения.

## 3. Выражение

Выражение вычисляет значение.

```java
2 + 3 * 4
```

Java сначала учитывает приоритет операций:

```text
3 * 4 = 12
2 + 12 = 14
```

Затем результат можно присвоить:

```java
int result = 2 + 3 * 4;
```

## 4. Команда

Statement просит программу выполнить действие.

```java
System.out.println(result);
```

Она печатает значение `result`.

## 5. Поток выполнения

По умолчанию Java выполняет statements сверху вниз.

```java
int x = 2;                 // шаг 1
x = x + 3;                 // шаг 2
System.out.println(x);      // шаг 3
```

Трассировка:

| Шаг | x | Действие |
|---:|---:|---|
| 1 | 2 | создана переменная |
| 2 | 5 | вычислено `2 + 3` |
| 3 | 5 | значение напечатано |

`if`, циклы, `switch`, exceptions и вызовы методов изменяют обычный маршрут.

## 6. Класс и объект

Класс описывает структуру объектов.

```java
class Student {
    String name;
    int score;
}
```

Объект — конкретный экземпляр:

```java
Student student = new Student();
student.name = "Amina";
student.score = 90;
```

Простая модель:

```text
class   = чертёж
object  = созданный по чертежу экземпляр
reference = способ найти объект
```

Граница аналогии: объект не обязан физически лежать рядом со ссылочной переменной.

## 7. Ссылка

```java
Student first = new Student();
Student second = first;
```

`first` и `second` указывают на один объект.

```java
second.name = "Dana";
System.out.println(first.name); // Dana
```

Присваивание ссылки не копирует объект.

## 8. Метод

Метод — именованное действие.

```java
static int add(int a, int b) {
    return a + b;
}
```

Вызов:

```java
int sum = add(2, 3);
```

Путь:

```text
передать 2 и 3
→ выполнить тело
→ вычислить 5
→ вернуть 5
→ присвоить sum
```

## 9. Ошибка компиляции и runtime failure

```java
int x = "five";
```

Не компилируется: типы несовместимы.

```java
String value = null;
System.out.println(value.length());
```

Компилируется, но при выполнении возникает `NullPointerException`.

Это два разных этапа:

```text
source code
→ compilation
→ bytecode
→ execution
```

## 10. Первый алгоритм чтения Java-кода

1. Найди переменные и их типы.
2. Найди начальные значения.
3. Отметь текущую строку выполнения.
4. Вычисляй выражения по одному.
5. После присваивания обновляй таблицу значений.
6. При вызове метода переходи в его тело.
7. При `if` выбирай только одну подходящую ветку.
8. При exception ищи, есть ли подходящий `catch`.

## Самопроверка

```java
int a = 4;
int b = a;
b = 9;
System.out.println(a + ":" + b);
```

Перед ответом заполни:

| Шаг | a | b |
|---:|---:|---:|
| 1 | | |
| 2 | | |
| 3 | | |

> [!answer]- Ответ
> Напечатается `4:9`. Для primitive `int` присваивание копирует значение.
